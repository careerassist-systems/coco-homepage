# グループホームCOCO ホームページ

公開先：https://ca-s.co.jp/coco/

## 直す場所

**`site/` フォルダの中を直してください。** ここが正です。

- `site/` を直して `main` に push すると、15分以内に https://ca-s.co.jp/coco/ に出ます（会社のリポジトリ cas-hp が自動で取り込みます）。
- 置けるのは、HTML・CSS・JS・画像・フォント・PDF などです。PHP と設定ファイル（.htaccess など）は取り込まれません。
- ファイルを消しても、本番からは自動で消えません。本番から消したいときは中庭さんに伝えてください。
- パスワード・鍵・入居者やお客様の個人情報は入れないでください（このリポジトリは公開です）。

## お問い合わせフォーム

- `site/contact.html` のフォームの送り先は `send.php` です（会社のサーバーにあります。このリポジトリにはありません）。
- 送ると、info@ca-s.jp へのメールと Slack の知らせが出ます。FormSubmit など外のサービスは使いません。
- フォームの項目を足す・名前を変えるときは、`send.php` も直す必要があります。先に中庭さんに伝えてください。

## いちばん上の階層のファイル

`index.html` などは、前の公開先（careerassist-systems.github.io/coco-homepage/）に来た人を、新しい場所へ案内するためのものです。サイトの中身ではありません。
